# Evidências da Visita

Esta pasta será preenchida **somente após a visita** e apenas com materiais cuja utilização tenha sido autorizada.

Sugestão de organização:

- fotos/
- respostas/
- observacoes/
- fluxos/
- indicadores/

## Regra
Não colocar aqui dados pessoais, documentos internos, imagens ou informações confidenciais sem autorização.

Os dados fictícios do protótipo não devem ser misturados com evidências reais.
